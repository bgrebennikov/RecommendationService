# Сервис рекомендаций банковских продуктов «Стар» (MVP)

Проект представляет собой минимально жизнеспособный продукт (MVP) рекомендательной системы для банка «Стар». Сервис анализирует исторические данные пользователей, типы используемых ими продуктов и финансовые транзакции для формирования персонализированных маркетинговых предложений через REST API.

---

## 🛠️ Технологический стек
* **Java 17 / 21**
* **Spring Boot 4.x** (Spring Web, Spring JDBC)
* **H2 Database** (Встраиваемая, файловая БД в режиме Read-Only)
* **SpringDoc OpenAPI (Swagger)** - для документирования REST API
* **JUnit 5 & Mockito** - для тестирования

---

## 📌 Архитектура проекта
Приложение спроектировано по слоям (Layered Architecture) с соблюдением принципов SOLID для обеспечения легкого расширения системы (добавления новых правил):

* `controller` - обработка входящих HTTP-запросов.
* `service` - координация процесса сбора рекомендаций.
* `rule` - изолированные бизнес-правила (компоненты `RecommendationRuleSet`), каждое из которых отвечает за логику конкретного продукта.
* `repository` - слой доступа к данным на базе `JdbcTemplate`.
* `dto` - объекты передачи данных.
